# 🎮 MAJD GAMES - منصة ألعاب متطورة بالذكاء الاصطناعي

## 📋 وصف المشروع

منصة ألعاب شاملة تستخدم الذكاء الاصطناعي المتقدم لتوليد وتطوير ألعاب حقيقية بشكل مستمر.

### المميزات الرئيسية:

✅ **توليد الألعاب بالذكاء الاصطناعي**
- ألعاب أكشن واقعية
- ألعاب RPG خيالية
- ألعاب استراتيجية متقدمة
- ألعاب محاكاة واقعية
- تصميم شخصيات وعوالم ديناميكية
- موسيقى وأصوات تصويرية

✅ **منصة متجر الألعاب**
- عرض وتصنيف الألعاب
- نظام البحث والتصفية
- تحميل الألعاب
- نظام التقييمات والتعليقات
- عرض الشاشات والفيديوهات

✅ **نظام المستخدمين**
- تسجيل واعتمادات آمنة
- ملفات شخصية متقدمة
- مستويات وإنجازات
- نظام التحالفات والتجمعات
- لوحة المتصدرين

✅ **لوحة التحكم للمالك**
- إدارة الألعاب المولدة
- عرض الإحصائيات الكاملة
- الإيرادات والأرباح
- إدارة المستخدمين
- التقارير المتقدمة

✅ **نظام الأتمتة والتطور المستمر**
- توليد ألعاب تلقائية كل فترة
- تحديثات ديناميكية للمحتوى
- نظام تعلم الآلة للتوصيات
- تحسين مستمر بناءً على ردود المستخدمين

## 🚀 بدء التشغيل السريع

### المتطلبات:
- Node.js 18+
- Python 3.10+
- PostgreSQL 13+
- Docker & Docker Compose

### خطوات التثبيت:

```bash
# 1. نسخ المستودع
git clone https://github.com/majdstoresa2-coder/MAJD-GAMES.git
cd MAJD-GAMES

# 2. نسخ ملف البيئة
cp .env.example .env

# 3. تثبيت Dependencies
npm install
pip install -r requirements.txt

# 4. تشغيل قاعدة البيانات
docker-compose up -d postgres

# 5. تشغيل جميع الخدمات
docker-compose up
```
