# MAJD GAMES Platform

## Overview
A complete gaming platform starter with:
- frontend storefront
- admin dashboard
- AI generation engine
- backend API
- PostgreSQL storage

## Quick Start

```bash
docker compose up --build
```

Frontend: http://localhost:5173
Admin: http://localhost:4173
Backend: http://localhost:4000
AI Engine: http://localhost:8000

## Project structure

- backend/
- frontend/
- admin/

- database/
